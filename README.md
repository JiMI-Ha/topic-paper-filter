# topic-paper-filter

A public Claude Code skill for topic-based literature discovery, evidence-backed paper summaries, and explainable paper ranking.

## What is included

- `.claude/skills/topic-paper-filter/SKILL.md`

## Usage

Copy the `.claude/skills/topic-paper-filter` directory into a Claude Code project, then ask Claude Code to use `topic-paper-filter` for a research topic.

Example:

```text
Use topic-paper-filter to find and rank papers about LLM over-refusal evaluation.
```

## Notes

This skill is intended to produce topic-specific reading recommendations, not a universal paper-quality leaderboard.
